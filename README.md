# AXIS · 웅비대대 AI 에이전트 포털

2040년 가상 부대 "웅비대대"의 하루를 픽셀 부대 맵으로 보여 주는 전시용 웹 포털입니다. 위병소·상황실·생활관·식당·의무실·연병장·수송부·TIGER 합성훈련장에서 사람과 차량이 움직입니다. 그때 생기는 데이터가 시설별 **AI 에이전트**를 거쳐 대대 통합관제 허브로 흘러가고, 에이전트의 권고를 **사람이 결정**하는 흐름을 보여 줍니다.

- 행사장에 띄워 두는 상시 화면(평소 모드)과, 컷신처럼 재생하는 약 86초짜리 시연(1분 시연)으로 이루어져 있습니다.
- 모든 데이터와 문구는 미리 쓴 목업입니다. 실시간 LLM이나 백엔드는 없습니다.
- 빌드 도구와 외부 라이브러리 없이 HTML·CSS·JavaScript(ES 모듈)와 Canvas만으로 동작합니다.

## 실행

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없고, 인터넷 없이도 동작합니다.

```bash
node server.mjs
```

브라우저에서 `http://localhost:5173`을 엽니다. `npm start`로 실행하면 브라우저가 자동으로 열리고, 윈도우에서는 `start.bat`을 더블클릭해도 됩니다.

- `index.html`을 파일로 바로 열면 브라우저 보안 정책 때문에 ES 모듈이 읽히지 않습니다. 반드시 위 서버로 여세요.
- 포트를 바꾸려면 `PORT=5174 node server.mjs`를 씁니다. 윈도우에서는 `set PORT=5174 && node server.mjs`입니다.
- 같은 네트워크의 다른 PC에서 접속하게 하려면 `HOST=0.0.0.0`을 함께 지정합니다.
- 서버는 포털에 필요한 파일(`index.html`, `styles.css`, `src/`, `assets/`의 글꼴·그림)만 내보내고, 나머지 경로는 404로 답합니다.

### 주소별 화면

| 주소 | 화면 |
| --- | --- |
| `/` 또는 `/#title` | 시작 화면 |
| `/#map` | 평소 모드 (행사장 상시 화면은 이 주소를 띄워 둡니다) |
| `/#demo` | 1분 시연 (열자마자 재생) |
| `/?from=63#demo` | 1분 시연을 63초 지점(ArmyGPT 장면 직전)부터 재생 |
| `/#sheet` | 캐릭터·차량·계급장 시트 |

## 화면 구성

### 시작 화면

게임 타이틀처럼 큰 AXIS 로고와 메뉴가 있고, 아래에는 7개 AI 에이전트가 홀로그램으로 떠 있습니다. 에이전트는 로봇이 아니라 부대 업무를 돕는 소프트웨어라는 뜻입니다. 메뉴는 ↑ ↓로 고르고 Enter나 클릭으로 들어갑니다(Esc 취소).

### 평소 모드

부대 전체(맵 1600×836)가 한 화면에 들어오고, 부대가 스스로 돌아갑니다.

- **캐릭터:** 장병·간부·로봇 약 150명이 역할에 따라 할 일을 스스로 고르고, 길을 찾아 움직입니다(배식, 근무 교대, 체력단련, 훈련, 진료 등).
- **경계:** 경계로봇이 울타리 안을, 드론이 울타리 밖 숲을 순찰하고, CCTV 14대가 부대 바깥을 감시합니다.
- **상시 시나리오:** 8종이 45~75초마다 그 자리에서 진행됩니다. 온열손상 예방, 드론·CCTV 훈련 분석, 수송 예방정비, 경계 이상 판별, 출입 차량 확인, 급식 수요 예측, 장비 반납 확인, 기상 연동 일정 전환입니다.
- **통신 로그:** 에이전트 사이의 통신이 화면 오른쪽 위에 토스트로 최근 3건까지 떴다가 사라집니다.
- **에이전트 분석 화면:** 맵의 에이전트(◆)를 누르면 그 에이전트가 보는 데이터 소스가 밝게 이어지고, 옆에 콘솔이 뜹니다.
  - 콘솔 내용: 하는 일, 핵심 지표, 최근 7일 추이, 연결된 데이터, 사람이 결정할 일
  - 미리 쓴 질문 3개: 누르면 답이 근거와 함께 나옵니다.

### 1분 시연 (약 86초)

웅비대대의 하루를 컷신으로 재생합니다. 장면마다 어떤 AI 에이전트가 어떤 데이터로 무엇을 하는지 보여 줍니다.

시연은 다섯 장(카테고리)으로 나뉩니다. 장이 바뀔 때마다 장 표지("2장 / 5 · 군수 에이전트")가 뜨고, 위쪽 띠에 지금 장이 금색으로 표시됩니다.

1. **인사 관리 에이전트:** 기상·AI 아미 워치(인사생활 → 의무지원) → 체력단련실 맞춤 운동 → 밀리테리아(맞춤 식단·식수 예측)
2. **군수 에이전트:** 대대 정비센터 예지 정비 → 부품 자동 발주 → 정찰로봇 운용 승인
3. **경계작전 에이전트:**
   - 위병소 정문 무인 출입
   - 남서 울타리: CCTV 감지 → 통합관제 AI가 드론·경계로봇 출동 → 열화상 판별 → 상황 종료
4. **훈련 성과 분석 회의(핵심 장면):**
   - AI 참모 분석 → 다음 주 훈련 계획 3안 → 디지털 트윈 검증 → 대대장 결심
   - 작전관 PC에서 **ArmyGPT**가 결심 내용을 군 서식 훈련 계획 문서로 작성 → 대대장 결재 → 각 중대 하달
5. **TIGER 합성훈련:** 결정한 계획대로 보완 훈련 → 결과가 다음 분석으로 돌아옴

**마무리:** 모든 데이터가 통합관제로 모이고, "AI 에이전트와 함께 강해지는 웅비대대" 카드가 마무리 음성이 끝날 때까지 떠 있습니다.

ArmyGPT 장면에 쓰는 실제 화면 캡처와 문서 그림(`assets/armygpt/`)은 저장소에 넣지 않았습니다. 이 그림이 없으면 그 장면의 PC 화면과 문서 자리가 빈 화면으로 나옵니다.

**대사 음성.** 대사 24줄과 마지막 문구는 화면 자막은 그대로 두고, 핵심만 짧게 음성(TTS)으로 들려줍니다(`assets/voice/`, Gemini TTS로 생성).

- 음성은 대사가 시작될 때 나오고, 앞 음성이 끝나기 전이면 끝난 뒤 이어집니다.
- 일시정지하면 함께 멈추고, 이동·중지하면 끊깁니다.
- AI 에이전트 목소리는 모두 같은 톤(같은 모델·목소리, 높이를 맞춤)입니다.
- 브라우저는 화면을 한 번 누르기 전에는 소리를 막을 수 있습니다. 시작 화면에서 메뉴를 눌러 들어가면 소리가 납니다. `#demo`를 바로 열 때는 화면을 한 번 클릭하세요.

**효과음.** 이상 감지 경고음, 정문이 열리는 소리, 드론 출동 소리, 에이전트가 일을 마칠 때의 체크음, 마지막에 모든 정보가 통합관제로 모일 때의 집결음 등 16곳에 효과음이 납니다(`assets/sfx/`, 7가지).

- 모두 직접 합성한 소리라 외부 음원을 쓰지 않았습니다.
- 대사 음성보다 낮은 음량이며, 대사와 겹쳐도 그 시각에 바로 납니다.
- 일시정지하면 함께 멈추고, 이동하는 동안에는 나지 않습니다.

## 조작

**평소 모드**

| 입력 | 동작 |
| --- | --- |
| 마우스 휠 / 드래그 | 확대·축소 / 이동 |
| `+` `-` · `0` | 단계별 확대·축소 · 전체 보기 |
| `F` | 에이전트 노드·연결선·패킷 표시 켜기/끄기 |

| 에이전트(◆) 클릭 | 에이전트 분석 화면 (`Esc`로 닫기) |
| `D` | 1분 시연 재생 |

**1분 시연**

| 입력 | 동작 |
| --- | --- |
| `Space` | 일시정지·재생 |
| `←` / `→` | 5초 뒤로 / 앞으로 |
| 화면 아래 진행 막대 | 눌러 끌면 그 시점으로 이동 (처음부터 빠르게 다시 돌려 1초 안팎 걸림) |
| `Esc` | 시연 중지 |

## 실제 이벤트 연결

브라우저 콘솔이나 다른 스크립트에서 이벤트를 넣으면, 맵 위로 패킷이 날아가고 통신 로그에 기록됩니다.

```js
agentPortal.emit('gate', 'hq', '차량 출입', '12가 3456 출입 승인')
agentPortal.agents()            // 에이전트 id 목록
agentPortal.goTo(732, 165, 2)   // 맵 좌표(1600×836)로 이동, 배율은 생략 가능
agentPortal.demo.play()         // 1분 시연 재생 · .stop() · .playing · .time
agentPortal.map.life.play('heat')   // 상시 시나리오 바로 실행
```

- `from`과 `to` 사이에는 연결선이 있어야 합니다. 허브 `hq`와는 모든 에이전트가 연결되어 있습니다.
- 백엔드와 붙일 때는 WebSocket·SSE 수신부에서 `agentPortal.emit(...)`을 호출하면 됩니다.

## 외부 공유 (선택)

[Tailscale](https://tailscale.com) Funnel이 설정된 윈도우 PC에서는 `share.bat`으로 포털을 인터넷에 열 수 있습니다.

- `share.bat`: 서버를 띄우고 Funnel을 8443 포트로 엽니다. 창에 나오는 `https://….ts.net:8443/` 링크를 보내면 됩니다.
- `share-stop.bat`: 8443만 닫습니다.
- 링크를 아는 사람은 누구나 로그인 없이 들어올 수 있습니다.
